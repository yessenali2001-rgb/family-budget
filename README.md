# Семейный бюджет

Простой сайт для учёта доходов и расходов семьи. Работает без сервера: данные хранятся в браузере (localStorage).

## Возможности

- Доходы и расходы по категориям, с указанием члена семьи и комментарием
- Переводы между членами семьи (например, Папа → Мама): не считаются доходом или расходом семьи и не тратят общий бюджет, но меняют остаток на личных листах
- Сводка за месяц: доходы, расходы, баланс; переключение между месяцами
- Остаток денег переходит из месяца в месяц: карточка «Остаток денег» показывает остаток с прошлых месяцев плюс баланс текущего
- Диаграммы: расходы по категориям и кто сколько потратил
- Общий бюджет семьи на месяц: сколько потрачено, сколько осталось и сколько можно тратить в день до конца месяца
- Итоги месяца: сколько отложено, сравнение с прошлым месяцем, главные категории, превышенные лимиты, график доходов и расходов за полгода, анализ и советы от Claude (на claude.ai) и общие «Выводы семьи». В начале месяца страница напоминает подвести итоги прошлого
- Месячные лимиты по категориям (жёлтый — потрачено 80%+, красный — лимит превышен)
- Отдельный лист для каждого члена семьи: свои доходы, расходы, баланс и операции (вкладки сверху). Лист «Вся семья» показывает всё вместе
- Свои члены семьи и категории; при выборе «Прочее» нужно написать, что именно купили — это видно в итогах месяца и в анализе
- Экспорт/импорт данных в JSON (резервная копия или перенос на другое устройство)

## Запуск

Откройте `index.html` в браузере — данные сохранятся только в этом браузере.

Если страница опубликована как артефакт на claude.ai, она подключается к общей базе: все, с кем поделились страницей (с правами Contributor), видят и заполняют один бюджет. Прежние записи из браузера можно перенести в общий бюджет одной кнопкой. Для публикации включите GitHub Pages в настройках репозитория (Settings → Pages → ветка с этими файлами).

Валюта задаётся константой `CURRENCY` в начале `app.js`.

## Общий бюджет через Supabase (для сайта на GitHub Pages)

Сайт на GitHub Pages может хранить данные в бесплатной базе Supabase. Тогда вся семья видит одни и те же записи, а вход — по семейному PIN-коду (на каждом устройстве вводится один раз).

У семьи один общий аккаунт Supabase, его пароль — это PIN. PIN проверяет Supabase и ограничивает число попыток, а правила таблицы пускают к данным только этот аккаунт.

1. Зайдите на https://supabase.com → **Start your project** → **Continue with GitHub**.
2. **New project**: название `family-budget`, придумайте пароль базы (он не понадобится), регион поближе (например, Frankfurt) → **Create new project**. Подождите 1–2 минуты.
3. **SQL Editor** → вставьте весь файл `supabase.sql` → **Run**.
4. **Authentication → Users → Add user → Create new user**: email `family@family-budget.app` (как в `config.js`), пароль — ваш PIN из 8+ цифр, галочка **Auto Confirm User** → **Create user**.
5. **Project Settings → API Keys**: скопируйте **Project URL** и **publishable** (или **anon public**) ключ в `config.js`.

Ключи из `config.js` не секретные: данные защищают PIN и правила из `supabase.sql`. Бесплатный проект Supabase засыпает после недели без посещений; данные при этом сохраняются, проект будится кнопкой **Restore** в панели Supabase.
